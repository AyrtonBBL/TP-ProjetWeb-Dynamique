# TP-ProjetWeb-Dynamique

--Présentation--

Ce projet a été réalisé dans le cadre du module GO & Web, dont l’objectif est de rendre un site web dynamique à l’aide du langage Golang, accompagné de HTML et CSS.
Le site développé simule une petite boutique en ligne : il affiche une liste d’articles, permet d’accéder au détail d’un produit et offre la possibilité d’ajouter de nouveaux articles via un formulaire.
Chaque étape correspond à un challenge du TP, et j’ai veillé à respecter toutes les consignes du sujet tout en essayant d’aller le plus loin possible, meme si je n'ai pas pu le finir entierement.

--Technologies utilisées--

Golang (net/http, html/template) – pour la partie serveur et la gestion des templates

HTML – pour la structure et les vues

CSS – pour le style et la mise en forme visuelle

Templates dynamiques Go 

Gestion de fichiers statiques(images, CSS)
